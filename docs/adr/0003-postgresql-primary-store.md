# ADR-0003：PostgreSQL 作为主存储

- 状态：Accepted
- 日期：2026-07-25

## 背景

主要读取模式是获取一个页面修订版；发布需要事务，跨页需要路径、环检测和引用反查。

## 决策

使用 PostgreSQL 保存正规化节点、边、引用、修订版和发布快照；视觉扩展字段使用受控 `JSONB`；搜索首版使用别名、标签和 `pg_trgm`。

## 备选

- Neo4j：多跳分析自然，但增加部署、事务和查询体系；
- MongoDB：页面读取直接，跨页完整性与原子发布更复杂；
- 仅 Git 文件：无法支撑动态反查、审计和未来编辑。

## 后果

- 一种数据库即可支撑 MVP；
- 全局深层图分析不是首版强项；
- 使用 Outbox 保留构建图数据库只读投影的路径。

## 复审触发

页面超过 10,000 且路径查询 P95 持续超过 500ms 时复审。
