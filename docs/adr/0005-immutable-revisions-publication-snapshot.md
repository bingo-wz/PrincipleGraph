# ADR-0005：不可变修订版与原子发布快照

- 状态：Accepted
- 日期：2026-07-25

## 背景

页面与下钻目标必须同时兼容；逐页发布可能让线上短暂出现断链，原地更新无法可靠回滚。

## 决策

已发布修订版不可修改。一个 `Publication` 固定空间内全部页面和场景的修订版映射，发布通过原子切换 `current_publication_id` 完成；回滚创建新的发布记录。

## 备选

- 逐页发布：操作简单但跨页不一致；
- 原地更新：表少但审计、缓存和回滚困难；
- 每次复制完整数据库：读取简单但成本高。

## 后果

- 发布前必须做整包闭包校验；
- 历史数据占用增加；
- 缓存 ETag 可由发布 ID 与内容哈希稳定生成。

## 复审触发

修订版存储成本影响数据库维护窗口时，评估冷历史归档，不改变语义。
