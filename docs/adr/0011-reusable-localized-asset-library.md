# ADR-0011：素材以稳定键复用，图形与多语言文案分离

- 状态：Accepted
- 日期：2026-07-25

## 背景

软件架构图、序列图和数据流图会反复出现 Web 客户端、DNS、CDN、负载均衡、服务实例、数据库、缓存和消息队列。每页重新绘制会产生视觉漂移、重复维护和搜索困难；把英文文字直接烘焙进图形，又无法支持中文内容和未来更多语言。

用户提供的 `system-design.excalidrawlib` 包含 24 组常见系统设计素材，可作为首批分类与视觉语义参考。该文件未提供可随开源仓库再分发的许可证证明，因此本轮不复制原始几何数据，只提炼通用组件类型，并使用项目自己的 CSS 图形实现。

## 决策

### 稳定资产模型

每个素材具有：

- `key`：跨页面稳定的 `kebab-case` 标识；
- `category`：客户端、网络、计算、数据、存储、消息或安全；
- `glyphKey`：与文案无关的图形实现；
- `name.zh/en` 与 `description.zh/en`：双语名称和说明；
- `aliases`：中英文别名，用于搜索；
- 节点通过 `assetKey` 引用素材，不复制图形配置。

图形不包含可见业务文字。`DNS`、`CDN` 等行业通用缩写可以作为图形内部标记，完整名称始终来自本地化文案。

### 渲染器复用

`SOFTWARE_ARCHITECTURE`、`SEQUENCE` 和 `LOGICAL_DATA_FLOW` 必须消费同一个 `assetKey`：

- 软件架构图将素材作为组件主体；
- 序列图将素材作为消息目标或参与者识别；
- 逻辑数据流图在外部实体、处理过程和数据存储形状内复用素材。

素材只表达“它是什么”，节点、边和 `Multiplicity` 分别表达“本页中的角色”“怎样流动”和“有多少个”。

## 选择理由

- 一个组件的图形、名称和别名只维护一次；
- 中文与英文共享同一稳定键，不产生两套知识节点；
- 图型切换时组件身份保持不变，降低认知切换成本；
- Schema 可以阻断悬空素材引用，搜索也能覆盖别名；
- 后续编辑器可以直接插入素材，但阅读器不必依赖 Excalidraw 运行时。

## 备选

### 直接提交 `.excalidrawlib`

保真度最高，但许可证和来源尚未确认，且页面运行时需要解析 Excalidraw 元素。本轮不采用；获得明确许可证后可作为可选导入格式。

### 每个页面维护独立图标

实现直接，但同一数据库或服务会逐页漂移，也无法统计复用位置，不采用。

### 使用文字或 Emoji 代替素材

成本最低，但系统组件难以快速扫描，跨平台字形也不稳定，只作为无法加载图形时的最终回退。

### 为中英文各建一套素材

可以单独优化排版，但会导致稳定键、引用和版本成倍增长，不采用。

## 异常与补偿

- `assetKey` 不存在：内容校验阻断发布；
- 图形实现不存在：回退 `application-server` 通用图形，同时记录 fallback；
- 某语言缺失：Schema 阻断发布，不静默使用空字符串；
- 素材重命名：稳定键不变，只更新本地化文案；
- 素材删除：先标记 deprecated，所有引用迁移后才能移除；
- 外部素材许可证不明：只允许作为设计参考，不进入公开源码或生产构建。

## 监控指标

- `asset_reference_missing_total`：目标为 0；
- `asset_renderer_fallback_total{glyphKey}`：正式内容目标为 0；
- `asset_usage_count{assetKey,diagramType}`：观察复用覆盖；
- `asset_search_zero_result_rate{locale}`：中文和英文均低于 15%；
- `asset_library_open_to_locate_rate`：从素材库成功定位知识节点的比例。

## 验收

- 首批不少于 20 个双语素材、7 个分类；
- 三种渲染器共用素材，不创建渲染器专属副本；
- 素材库支持中英文切换、分类、搜索、稳定键和复用位置；
- 多实例服务同时显示素材图形与 `N/G/T` 数量语义；
- 非法 `assetKey` 被语义校验拒绝；
- 原始参考 `.excalidrawlib` 未进入公开仓库。

## 复审触发

出现可合法再分发的 Excalidraw、Figma 或云厂商图标包，或者作者端需要自定义上传素材时，复审导入、版本、去重和许可证字段。
