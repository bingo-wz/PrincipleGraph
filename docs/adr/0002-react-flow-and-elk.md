# ADR-0002：画布采用 React Flow，自动布局采用 ELK

- 状态：Accepted
- 日期：2026-07-25

## 背景

页面要呈现 8–20 个主要节点、明确方向、分组容器、下钻按钮和说明联动。

## 决策

使用 React Flow 构建语义画布；人工坐标优先，缺少坐标时在 Web Worker 中使用 ELK Layered 从左到右布局。

## 备选

- Excalidraw：手绘体验更强，但语义数据需要额外同步层；
- Cytoscape.js：图分析强，产品白板交互需更多定制；
- Dagre：接入简单，但复合图与端口控制较弱。

## 后果

- 节点可以使用标准 React 可访问组件；
- 大图需要 memo、按页加载和 LOD；
- ELK 超时必须回退到保存坐标或简化布局。

## 复审触发

100 节点 fixture 在目标设备切层 P95 超过 800ms，且常规优化无效时复审。
