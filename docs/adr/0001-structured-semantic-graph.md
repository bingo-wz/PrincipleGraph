# ADR-0001：核心模型使用结构化语义图

- 状态：Accepted
- 日期：2026-07-25

## 背景

产品需要稳定下钻、流程校验、双向引用、搜索和版本发布。自由白板元素本身无法可靠表达这些语义。

## 决策

核心数据由 `Page / Node / Edge / Drill Link / Reference / Explanation` 组成。手绘样式属于渲染层，自由标注未来作为 overlay，不进入流程真相。

## 备选

- Excalidraw scene JSON 作为真相：编辑自由，但稳定引用和图校验成本高；
- 纯 Markdown + Mermaid：维护简单，但交互和节点级双链受限。

## 后果

- 可以自动发现断边、不可达出口和下钻环；
- 作者必须遵守 Content Schema；
- 自由绘图能力延期。

## 复审触发

超过 30% 的内容无法用既有节点/边语义表达时复审。
