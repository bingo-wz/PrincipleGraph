# ADR-0006：MVP 使用 Git 内容工作流

- 状态：Accepted
- 日期：2026-07-25

## 背景

Content Schema 和交互模型尚未经过用户验证。此时建设完整 Web 编辑器会同时引入权限、冲突合并、自动保存和画布编辑问题。

## 决策

MVP 使用 Git 中的 JSON/YAML 内容包，经过 schema、图语义、技术和教学审核后导入。Web 编辑器进入 Phase 2，并必须读写同一个 Schema。

## 备选

- 立即建设 Web 编辑器：作者体验好，但增加 4–6 周并可能固化错误模型；
- 数据库后台直接编辑：快但不可复现、难审计；
- Markdown 手工页面：缺少稳定图语义。

## 后果

- 首批作者需要 Git 能力；
- 内容历史、差异和 Code Owner 审核直接可用；
- 先把工程投入放在浏览与理解价值上。

## 复审触发

Schema v1 连续两个迭代稳定，且至少 5 名非开发作者有持续贡献需求时启动 Web 编辑器。
