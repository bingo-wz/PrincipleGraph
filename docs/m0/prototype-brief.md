# M0 低保真原型 Brief

## 视觉主张

像一张被认真整理过的工程白板：纸张质感、深墨文字、单一橙色强调；主链路始终比界面 chrome 更醒目。

## 内容计划

1. 顶部只负责定位：品牌、当前页面、搜索；
2. 左侧只负责路径：8 个页面和当前下钻历史；
3. 中间只负责理解：一条按视口宽度蛇形折行、仍保持单一执行方向的完整主链路；
4. 右侧只负责解释：当前节点、上下游、下钻和双向引用；
5. 底部只负责图例和画布操作。

## 交互主张

1. 选中节点时，节点、相邻边和说明面板共同聚焦；
2. 下钻时，旧链路淡出并切换到下一层，面包屑同步增加；
3. 打开相关引用后保留明确“返回来源”，证明双链不是普通跳转。
4. 多实例、多线程和连接池节点同时显示数量类型与当前请求落点。

## 必测假设

| 假设 | 原型证据 | 判定 |
|---|---|---|
| 用户能区分流程边与下钻 | 流程边始终在画布；下钻只在节点按钮出现 | 5 人中 ≥4 人正确 |
| 固定右侧说明优于画布注释 | 选中节点后说明面板不遮挡主链路 | 5 人中 ≥4 人无需提示找到解释 |
| 单页 8–10 个主节点可理解 | 原型 8 页均为 8–10 个节点 | 主链路复述率 ≥80% |
| 双击不是唯一入口 | 节点同时提供显式“进入原理”按钮 | 无用户因不知道双击而失败 |
| 用户不会在下钻后迷路 | 面包屑、来源页和“返回上层”同时存在 | 5 人中 ≥4 人独立返回 |
| 默认视口不需要横向找链路 | 桌面 4 列、窄屏 2 列蛇形折行 | 5 人中 ≥4 人无需横向滚动完成复述 |
| 用户不把示意数量当成真实数量 | 数量标记区分固定、示意与动态 N，高亮当前落点 | 5 人中 ≥4 人正确解释 `N / T / 1` |

## 原型范围

- 包含 8 个页面和真实节点标签；
- 支持节点选择、说明切换、显式下钻、面包屑、返回、相关引用；
- 支持搜索页面/节点并打开对应页面；
- 支持主链路/异常边图例；
- 支持多实例、多线程、队列和连接池的数量语义；
- 不实现自由拖拽连线、持久化编辑、登录、自动布局或后端请求。
